# Moonlight Desk 初版

面向办公的 Moonlight 定制客户端，首个目标平台为 Apple Silicon Mac。配套 [Sunshine Desk](https://github.com/linrong123/sunshine-desk) 在被控端只提供 Desktop，不提供新增应用入口。本客户端没有按名称隐藏 Steam，也没有复刻传输、解码或配对协议。

## 当前功能

- 中文工作台（远控软件式界面）：顶部输入被控端 IP 或域名后点“连接”，新地址自动添加→配对→进入桌面，已有设备直接进入；下方“我的设备”卡片显示在线状态、名称、地址和会话状态。界面细节见下文“界面说明”。首次连接仍走原有 PIN 配对。
- 配对时向被控端发送本机真实名称（Mac 的“电脑名称”，去除控制字符、最长 64 字节 UTF-8，取不到时为 `Moonlight Desk`），便于被控端识别是哪台设备。配对窗口提示在被控电脑弹出的窗口中输入验证码；旧版或原版 Sunshine 不弹窗时，仍在其网页管理后台的 PIN 页面输入。协议见[连接与授权契约](CONNECTION.md)。
- 每次连接确认：被控端在已配对 HTTPS `serverinfo` 宣告 `OfficeConnectConfirm=1` 时，启动或恢复 Desktop 前先请求被控端用户允许。等待期间串流窗口与工作台都显示“正在等待被控端确认…”，可点“取消”撤回请求；被控端拒绝显示“被控端拒绝了连接”，60 秒未处理显示“被控端未在 60 秒内确认”。被控端批准后工作台回到“正在连接”。若启动或恢复仍被被控端以 403 `Host approval required` 退回（许可已用掉或过期），显示“被控端需要本机确认，请重新连接”，并尽力发送一次取消，撤回被控端因此自动弹出的确认窗。拒绝、超时和 403 都不自动重试；拒绝或超时后 30 秒内重连，被控端直接返回原结果，客户端照常显示对应提示；未宣告该能力的主机保持原流程。
- 一台 Mac 可启动多台电脑的独立桌面窗口。主界面保持可用，重复打开同一设备会显示已有窗口；连接中的工具栏可点“设备列表”图标返回工作台。关闭管理窗口只隐藏，显式退出会先断开各会话。多进程隔离已通过本地测试，多台真实主机同时串流仍待验收。
- 已建立桌面串流发生连接中断后，旧连接清理完再退避重连。主动断开、认证/配对失败、受保护内容或编码转换错误不循环重试；恢复可取消。
- Mac 串流窗口顶部的原生工具栏，布局参照常见远控软件：左侧是连接信息胶囊（状态圆点、加粗设备名、灰色中文统计摘要如“延迟 12 ms · 60 帧/秒 · 18.5 Mbps”和 ⓘ 图标，悬停显示详情，点击打开/关闭可拖动、不抢键盘焦点的连接信息浮窗）；中间居中一组图标：显示（远端分辨率、Windows文字和图标缩放）、鼠标与键盘（本机鼠标/远端鼠标/游戏模式，附说明；暂停输入）、全屏（直接切换，图标和提示随状态变化，⌃⌥⇧X）、设备列表；最右侧是红色“断开”。菜单每组只勾当前项。窗口模式占用独立顶部区域，不遮挡远端内容；窄窗口使用系统溢出菜单，按同样分类显示文字。全屏（macOS 独立空间）时工具栏和菜单栏自动隐藏，鼠标移到屏幕顶部再出现。详见 [显示设置](DISPLAY_SETTINGS.md)。
- 选择新分辨率立即出现确认框，确认后短暂重连，不再需要“应用”按钮。取消保留原值，不注销 Windows；服务端和显示器必须支持所选模式。请求的串流尺寸不等于已经验证的 Windows 物理显示模式。
- Windows缩放从新版 Sunshine Desk 读取当前值和支持档位（例如125%、150%、200%），选择后即时请求修改并核对实际值，不重连。它改变Windows系统文字和图标大小，并非Mac画面放大。旧版主机、驱动不支持、目标显示器不明确或自定义DPI时禁用并说明原因。详见[显示设置](DISPLAY_SETTINGS.md)。
- 鼠标与分辨率按主机记忆；每次串流使用独立设置副本，不改变其他电脑的全局偏好。
- 办公本地光标通过配对后的 HTTPS 请求让 Sunshine Desk 隐藏视频里的远端光标。原版 Sunshine 无此能力时保留远端光标，并显示说明。

恢复调度最多 10 次、约一分钟的退避预算，网络握手和清理本身也需要时间。首次连接失败不会无限自动重试。Windows 密码仍由 Windows 锁屏界面处理；本软件不保存、自动输入或绕过 Windows 登录密码。

## 界面说明

办公界面代码都在 `app/office/`，统一使用 `deskstyle.js` 的浅色配色、圆角、间距和字号；上游界面只在办公模式（管理进程或会话进程）下换皮，原版 Moonlight 启动路径不受影响。

- 工作台（`DeskHome.qml` + `DeskView.qml` + `DeskConnector.qml`）
  - 地址栏：接受 IPv4、域名、`主机:端口`、IPv6（可带方括号），默认端口 47989。按“连接”或回车提交；进行中按钮禁用并在下方显示进度。
  - 地址已在设备列表中（比较全部已知地址）：已配对且在线直接进入桌面；已有会话则显示其窗口；未配对先弹出 4 位 PIN 配对。
  - 新地址：添加 → 等待设备出现（15 秒）→ 配对 → 确认已配对（30 秒）→ 进入桌面。任一步失败只提示一次中文原因，不自动重试；配对失败不会再次弹出配对。卡片对“检测中”的设备发起连接时，等状态出来再继续（同样限 15 秒）。IPv6 按 RFC 5952 规范化后比较。
  - 配对窗口可“取消”：只在本地放弃，地址栏立即可用。上游无法中止已发出的配对请求，它会在后台继续，晚到的结果被忽略；因此同一时间只有一个添加、一个配对请求：再次配对同一台电脑显示原 PIN 继续等待，配对另一台电脑或添加新地址会提示稍后再试。
  - 设备卡片：状态点（绿在线 / 黄检测中、未配对 / 灰离线 / 蓝会话中）、名称、地址（默认端口不显示）、状态文字和主按钮（连接 / 显示桌面 / 配对 / 唤醒 / 离线）。双击卡片等同“连接”。
  - “⋯”菜单（右键卡片同样打开）：断开（有会话时，含等待被控端确认）、配对（在线未配对）、唤醒（离线且可唤醒）、重命名、移除（有会话时隐藏）。每个操作执行前再次核对条件。
  - 没有设备时显示空状态和使用提示。
- 设置（`DeskSettings.qml`，工作台右上角齿轮）：只读写现有 `StreamingPreferences`，不另存一份。
  - 画面：分辨率（跟随本机屏幕或 720p/1080p/1440p/4K）、帧率、自动码率开关与手动码率滑杆、编码（自动 / 兼容优先 H.264 / 画质优先 HEVC / 更省流量 AV1）、文字更清晰（YUV 4:4:4）、全屏或窗口。
  - 声音：在本机或被控电脑播放、切到其他窗口时静音。
  - 键鼠：系统快捷键发给被控电脑（仅全屏时 / 始终）、交换左右键、反转滚轮。鼠标模式在桌面窗口工具栏的“鼠标与键盘”图标菜单中按设备切换。
  - 关于：版本、许可证（GPLv3，基于 Moonlight）。“高级设置”打开原版设置页，只有该页显示原版顶部工具栏。
  - 这里改的是全局默认值；各设备在桌面工具栏记住的分辨率、鼠标模式以及每次会话的设置副本不受影响。
- 其他页面：退出确认（`DeskDialog.qml`，有会话时提示会断开所有远程桌面）、错误提示与上游消息框（浅色、中文按钮、无帮助按钮）、连接中 / 退出中过渡页（`DeskProgress.qml`，上游英文阶段文字统一显示为“正在连接远程桌面…”或“正在退出…”）。工作台不再提供上游“添加电脑”入口，地址栏取代它。

## 构建与启动

需要 macOS、Xcode 命令行工具、Python 3 和 Qt 6.11.2 macOS SDK。所有额外依赖可装在项目内：

```bash
git clone --recursive https://github.com/linrong123/moonlight-desk.git
cd moonlight-desk
python3 -m venv .work/py
.work/py/bin/pip install aqtinstall==3.3.0
.work/py/bin/aqt install-qt mac desktop 6.11.2 clang_64 -O .work/Qt -m qtshadertools qtimageformats
bash office/macos/test.sh
bash office/macos/build.sh
open dist/MoonlightDesk.app
```

已有 Qt 时设置 `OFFICE_QT_BIN` 为对应 `bin` 目录。脚本沿用上游依赖下载器，生成 ARM64 应用和 ZIP；本地临时构建目录保留在 `build/`。这是本地签名的开发版，尚无 Developer ID 签名/Apple 公证。

办公版拥有独立应用标识、配对身份及偏好，与原版 Moonlight 分开。首次需重新添加主机并经本人确认 PIN，不导入原版配对私钥。构建脚本不会替换 `/Applications/Moonlight.app`。

项目现名为 Moonlight Desk，配套服务端为 Sunshine Desk。为保留既有设置，早期 `MoonlightOffice` 的应用标识、设置目录和内部协议名继续沿用；`office/` 源码目录也保留，避免仅为改名扩大上游合并差异。新的应用包与 ZIP 使用 `MoonlightDesk` 名称。

连接后可直接操作工具栏。相对鼠标模式会捕获指针，使用 Moonlight 原有 `Control + Option + Shift + Z` 释放后再操作工具栏。工具栏只作用于当前串流；工作台中的全局画质、码率、声音设置用于后续新建的会话，不修改已经打开的其他桌面。

测试新版本时可使用 `OFFICE_OUTPUT_DIR="$PWD/dist/desk-multi" bash office/macos/build.sh`，再自行打开该目录中的应用。脚本拒绝替换仍在运行的目标应用包。开发时保留旧连接不动，只构建新包；同一设备请先结束旧版本连接再使用新版本进入。

## 交付范围与验收

本轮保留上游编码/传输性能，不宣称降低跨洋基础延迟，不自动安装虚拟显示驱动，也不包含公网中转服务。主机发现、首次账户设置和配对仍需用户完成，尚不是最终零配置安装体验。

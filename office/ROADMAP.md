# 路线图

Moonlight Desk（主控端）与 [Sunshine Desk](https://github.com/linrong123/sunshine-desk)（被控端）的功能级里程碑。一项一行，完成时勾选并附提交。

## M0 上游合并卫生

- [ ] Sunshine Desk 收缩上游文件差异并合并到上游最新 tag
- [ ] 两端每周自动对上游最新 tag 做合并试算并报告冲突
- [ ] 0.3.0 遗留实机验收：Windows 缩放写入、分辨率切换、全屏工具栏、两台主机同时串流

## M1 直连与授权（[设计](CONNECTION.md)）

- [ ] 主控端发送真实设备名，配对界面提示在被控端弹窗输入验证码
- [ ] 被控端原生授权弹窗（输入 4 位验证码）
- [ ] 被控端托盘管理已授权设备（禁用/删除立即断开）
- [ ] 可选「每次连接需本机确认」及主控端等待确认界面
- [ ] 被控端默认强制串流加密

## M2 被控端可独立安装

- [ ] 独立安装包身份、服务名与配置目录，可与官方 Sunshine 共存
- [ ] 首次启动无需网页建立管理员账户
- [ ] 安装包签名

## M3 主控端扩展

- [ ] Windows 主控端（Windows 原生工具栏）
- [ ] 文本剪贴板同步
- [ ] 文件传输

## M4 远期

- [ ] 用户自建中转（连接路线 relay）
- [ ] 账号同步设备列表
- [ ] 手机端评估

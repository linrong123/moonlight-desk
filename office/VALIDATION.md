# 首版验证记录

日期：2026-11-19。实际开发机及配对信息不纳入公开仓库。

## 已通过

- Apple Silicon、Xcode 27.2、Qt 6.11.2 下完整 release 构建。
- C++ 恢复策略测试：退避、预算、主动取消、频繁掉线不重置预算、稳定连接后新 episode、分辨率白名单。
- QML 恢复序列测试 11 passed、0 failed：等待 cleanup、仅一次调度、等待中取消、重试实例交接、不支持恢复时释放；真实 Escape/Back 事件不冒泡离开恢复页，取消/迟到清理只完成一次。
- 源码核查：已配对 HTTPS 的服务器信息查询不走 HTTP 降级；TLS/认证失败不归入网络瞬断；光标写入受服务端现有配对认证约束。
- 设置快照测试：全部偏好属性及非 QML packetSize 正确复制，改分辨率/鼠标不污染原始对象或持久化全局设置，随 Session 所有者销毁。
- 光标安全切换策略测试：等待/失败时保留本地可见指针，仅在主机成功确认后启用远端/相对模式；原版主机保留兼容行为。
- 独立 ARM64 包生成，111 个 Mach-O 文件的非系统依赖均包含在包内；深度严格签名校验通过；包内程序直接启动并输出 `MoonlightOffice 0.1.0`，正常退出。
- 打包排除 Qt 自动附带但本项目不使用的 Mimer SQL 插件（它依赖外置商业客户端）；未改系统 Qt 或安装 SQL 客户端。最终包检查不允许遗留缺失依赖。

## 双端验收尚未完成

本地通过不等于真实主机验收通过。需要配套 Office host 后验证：

1. 新身份配对、点击唯一 Desktop 进入，已有应用目录不由客户端隐藏。
2. Windows 锁屏 → 连接 → 人工解锁 → 若串流进程迁移则自动恢复。主动断开/取消不会重进，不注销、不重启 Windows。
3. 1080p → 1440p → 4K，分别记录请求尺寸、Windows 实际显示模式、解码帧尺寸；不支持模式显示错误而非假成功。
4. 本地/远端鼠标反复切换，单指针、点击位置一致；请求丢失或断网时仍能取消/重试。
5. 服务端重启串流进程、短暂断网、配对撤销、快速反复掉线，不并发建立重复连接。

首版没有更改正在工作的官方 Moonlight/Sunshine，不包含虚拟驱动安装、Windows 密码保存或公网中转。未进行 Developer ID 签名或公证。
